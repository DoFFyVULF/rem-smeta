# РемСмета

Онлайн-калькулятор стоимости ремонта квартир. Позволяет за 5 шагов рассчитать предварительную смету с учётом площади, типа планировки, вида ремонта, состояния квартиры, города и дополнительных работ.

## Возможности

- **5-шаговый визард** — пошаговый переход от параметров квартиры до отправки заявки
- **Живой расчёт цены** — предварительная стоимость пересчитывается мгновенно при каждом изменении
- **Типы квартир** — студия, 1–4+ комнатные квартиры с автоподстановкой параметров
- **Виды ремонта** — косметический, капитальный, дизайнерский, под ключ
- **Состояние квартиры** — новостройка, white box, вторичка, после косметического ремонта
- **Дополнительные работы** — демонтаж, электрика, сантехника, выравнивание стен, потолки и др.
- **География** — Москва (×1.2), Санкт-Петербург (×1.1), другие города (×1.0)
- **Срочный ремонт** — коэффициент ×1.15
- **Сохранение черновика** — прогресс сохраняется в localStorage
- **Адаптивный дизайн** — корректно работает на десктопе и мобильных устройствах

## Технологии

- [Next.js](https://nextjs.org/) 16 — React-фреймворк
- [React](https://react.dev/) 19 — UI-библиотека
- [TypeScript](https://www.typescriptlang.org/) — типизация
- [Tailwind CSS](https://tailwindcss.com/) 4 — утилитарные стили

## Структура проекта

```
app/
  page.tsx              — главная страница
  layout.tsx            — корневой layout
components/
  calculator/           — компоненты калькулятора
    CalculatorWizard.tsx   — оркестратор шагов
    ApartmentParamsStep.tsx — шаг 1: площадь и планировка
    RepairTypeStep.tsx     — шаг 2: вид ремонта
    ConditionStep.tsx      — шаг 3: состояние квартиры
    ExtrasStep.tsx         — шаг 4: дополнительные работы
    FinalStep.tsx          — шаг 5: город, срочность, контакт
    PriceSummary.tsx       — отображение расчётной стоимости
  ui/                   — переиспользуемые UI-компоненты
hooks/
  useCalculator.tsx     — централизованное управление состоянием (Context + useReducer)
lib/
  calculate.ts          — чистая логика расчёта стоимости
  constants.ts          — цены, коэффициенты, списки опций
  types.ts              — TypeScript-интерфейсы
  storage.ts            — работа с localStorage
  format.ts             — форматирование чисел
```
